# Task 3: Monthly Spending Prediction

ทำนายยอดใช้จ่ายใน 30 วันข้างหน้า หน่วยบาท วัดด้วย 1 / (1 + NMAE) โดย NMAE คือผลรวมค่าคลาดเคลื่อนสัมบูรณ์ หารด้วยผลรวมยอดจริง

## ข้อมูล

- train 104,000 แถว 32 ฟีเจอร์ ค่าว่างเฉลี่ย 5.5%
- เป้าหมายเบ้ขวามาก: 48% เป็น 0, median 79 บาท, สูงสุด 300,000 บาท

## วิธีทำ

- CatBoost ใช้ loss แบบ MAE บนยอดเงินจริง ไม่แปลงเป็น log เพราะ metric วัดบนหน่วยบาทโดยตรง
- KFold 3-fold เฉลี่ยคำทำนายบน test และตัดค่าติดลบเป็น 0

## ผลในเครื่อง

| โมเดล | คะแนน | MAE (บาท) |
|---|---|---|
| ทาย median ทุกแถว | 0.500 | 10,496 |
| CatBoost 3-fold | 0.775 | 3,042 |
| CatBoost 5-fold เทรนนานขึ้น | 0.774 | ไม่ได้บันทึก |

## ไฟล์
