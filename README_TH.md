สำหรับงาน 4 ค่าในคอลัมน์ `task4` ของแม่แบบเป็นตัวเลข แต่ label ใน `train.csv` เป็นข้อความตามรายการข้างบน โปรแกรมคง label ข้อความที่เรียนจาก CSV ไว้ในผลทำนายตามโจทย์และสไลด์ ไม่แปลงเป็นรหัสคลาสภายในโมเดล

## ติดตั้งและรัน

เปิด PowerShell ที่โฟลเดอร์ `solution/` หากเป็นสำเนาใหม่ที่ยังไม่มีสภาพแวดล้อม ให้ติดตั้ง dependency ตาม `requirements.txt`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

ตรวจพบข้อมูลและรูปแบบคอลัมน์ก่อนฝึก:

```powershell
.\.venv\Scripts\python.exe run.py audit
```

ฝึกงานตารางที่ 1, 2, 3 และ 5 ด้วยโปรไฟล์สมดุล:

```powershell
.\.venv\Scripts\python.exe run.py train --tasks 1 2 3 5 --profile balanced --folds 3 --threads 8
```

ฝึกตัวจำแนกภาพ ResNet-18 ที่เริ่มจากน้ำหนักซึ่งฝึกมาก่อน:

```powershell
.\.venv\Scripts\python.exe run.py train --tasks 4 --profile balanced --epochs 5 --batch-size 128
```

รวมคำทำนายและตรวจไฟล์ส่ง:

```powershell
.\.venv\Scripts\python.exe run.py assemble
.\.venv\Scripts\python.exe run.py validate --file outputs/main/submission.csv
.\.venv\Scripts\python.exe report_results.py
```

ตัวเลือกโปรไฟล์ `quick`, `balanced`, `strong` ใช้เวลาฝึกต่างกัน โปรไฟล์ที่ใหญ่ขึ้นไม่ได้รับประกันคะแนนดีขึ้น หากต้องรันซ้ำด้วยการตั้งค่าอื่น ให้บันทึกผลแต่ละครั้งแยกจากกันก่อนนำผลมารวม

ภาพงาน 4 ถูกแตกไว้ใน `04_image_classification/` แล้ว หากเตรียมข้อมูลใหม่และต้องการดาวน์โหลด archive จากลิงก์ที่โจทย์ให้พร้อมแตกไฟล์ ให้ใช้คำสั่งนี้ (ต้องมีการเชื่อมต่ออินเทอร์เน็ต):

```powershell
.\.venv\Scripts\python.exe prepare_images.py --download
```

### สมุดอธิบายเดิมสำหรับเครื่องและ Kaggle

ส่วนนี้หมายถึง `Player_Intelligence_System.ipynb` สำหรับอ่านคำอธิบายและผลในเครื่อง ส่วนการทำงานร่วมกันบน Colab ให้เปิด `Player_Intelligence_Colab.ipynb` ตามลิงก์ต้นเอกสาร โดยสมุด Colab ตั้ง `RUN_TRAINING=True` และให้กำหนด `DATA_PATH` กับโฟลเดอร์ผลบน Drive ก่อนรัน

โน้ตบุ๊กประกอบด้วย source code ที่จำเป็นในตัว ไม่ต้องแนบไฟล์ source แยกอีกครั้ง จุดเริ่มต้นจะค้นหา `sample_submission.csv` ที่ไม่ซ้ำในข้อมูลที่แนบมาเพื่อกำหนด `DATA_ROOT` โดยอัตโนมัติ ค่า `RUN_TRAINING=False` เป็นค่าเริ่มต้นเพื่อเปิดดูรายงานและ metrics ที่มีอยู่ โดยไม่เผลอเริ่มการฝึกที่ใช้เวลานาน หากต้องการฝึกบนเครื่องที่มี GPU ให้เปลี่ยนเป็น `True` ด้วยตนเอง ตรวจ `DATA_ROOT` และความพร้อมของภาพก่อนเริ่ม

รันในเครื่องกับ `.venv` เหมาะสำหรับตรวจข้อมูลและฝึกงานตาราง ส่วนงานภาพใช้เวลามากกว่าและได้ประโยชน์จาก GPU; Kaggle Notebook ที่เปิด GPU เหมาะสำหรับทดลองงานภาพ ตรวจ environment และผลลัพธ์ใน notebook ให้ตรงกับไฟล์ที่จะส่งก่อนสรุปผล

## ผลลัพธ์

ไฟล์อยู่ใน `outputs/main/` โดยทั่วไปประกอบด้วยรายงานตรวจข้อมูล, ค่าเมตริกและผล cross-validation ใน `task*_metrics.json`, คำทำนายแบบ out-of-fold, คำทำนาย test และโมเดลของแต่ละ fold งานภาพจะมีรายงาน validation และ checkpoint งานที่ 5 จะมีคะแนนผิดปกติและป้ายทำนายที่ได้จากเกณฑ์ contamination ที่ตั้งไว้

ก่อนส่ง ให้ตรวจว่า `submission.csv` มี 25,889 แถว เรียง `id` ตรงกับแม่แบบ คอลัมน์ครบ ไม่มีค่าว่าง และค่าตรงชนิดคำตอบ โดย Task 4 เป็นชื่อเกม เก็บ `metrics.json` ของการรันที่เลือกไว้ประกอบรายงาน ห้ามเขียนคะแนนหรือผล validation ที่ยังไม่ได้รันจริงลงในรายงาน

ไฟล์ metrics ที่สร้างจากการรันจริง: `outputs/main/task1_metrics.json`, `outputs/main/task5_metrics.json` ไฟล์จะเปลี่ยนตามการรันล่าสุด อ่านค่าพร้อม `profile`, `seed`, `folds` และหมายเหตุใน JSON ก่อนนำไปเขียนรายงาน งาน 5 ระบุ `macro_f3: null` เมื่อไม่มีเฉลยให้คำนวณ

## แนวทางที่ใช้และข้อจำกัด

- งาน 1 และ 2 ใช้การแบ่ง fold แบบรักษาสัดส่วนคลาส งาน 1 เลือก threshold จากค่า OOF เพื่อให้เหมาะกับ macro F2 แต่คะแนนที่เลือก threshold และรายงานจาก OOF ชุดเดียวกันมีแนวโน้มสูงกว่าความจริง ควรรายงาน threshold 0.5 เทียบไว้ และใช้ holdout อิสระหรือตรวจซ้ำแบบ nested validation เมื่อต้องสรุปผลจริง
- งาน 3 ใช้ MAE กับยอดเงินจริงหน่วยบาท แล้วคำนวณคะแนนตามสูตร NMAE ของโจทย์ ไม่แปลงเป้าหมายเป็น log อย่างเดียว เพราะจะให้น้ำหนักกับข้อผิดพลาดคนละแบบ
- งาน 4 ใช้ ResNet-18 ที่เริ่มด้วยน้ำหนัก pretrained ตามโจทย์ และแบ่ง validation ด้วยการ stratify พร้อมจัดภาพ train ที่มี hash ไบต์ตรงกันไว้ฝั่งเดียวกัน ห้ามใช้ภาพ test ฝึกหรือเลือกโมเดล และห้ามทำ AutoML
- งาน 5 ไม่มี train หรือป้ายกำกับตรวจสอบในชุดข้อมูลที่ให้มา โมเดลใช้ Isolation Forest และคะแนนแนวโน้มตามค่า contamination ตั้งต้น 0.20 ซึ่งเป็นสมมติฐานสำหรับสร้างลำดับ/ป้ายทำนาย ไม่ใช่สัดส่วน anomaly ที่ยืนยันจากเฉลย จึงยังยืนยันคะแนน macro F3 จากข้อมูลในเครื่องไม่ได้

สไลด์งานระบุห้ามฝึกจาก test และห้ามสร้าง pseudo-label ขณะที่งานที่ 5 ให้มาเฉพาะ test และระบุเป็นงาน unsupervised แนวทางในโค้ดจึงตีความงานที่ 5 เป็นข้อยกเว้นเฉพาะงานเพื่อสร้างคะแนนจากข้อมูลไร้ป้ายกำกับ ควรถามอาจารย์หรือ TA ให้ชัดเจนก่อนส่งว่าการ fit ตัวตรวจจับจากข้อมูล test ในงานนี้ได้รับอนุญาตหรือไม่
