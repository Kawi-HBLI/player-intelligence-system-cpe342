# ข้อค้นพบจาก Kaggle และผลการทดลอง (10 พ.ย. 2026)

## กติกาและการให้คะแนนที่ยืนยันจากหน้า Kaggle และสไลด์ Instruction

- Metric: T1 Macro F2, T2 Macro F1, T3 = 1/(1+NMAE), T4 Macro F1, T5 Macro F3
- คะแนนรวมเป็นค่าเฉลี่ยถ่วงน้ำหนัก (w1S1+...+w5S5)/Σw โดยไม่เปิดเผยค่า w
- ห้ามใช้ test ในการเทรน, ห้าม AutoML, ใช้ pretrained ได้เฉพาะ T4
- หน้า submit แสดงโควตา 5 ครั้งต่อวัน แต่ควรถือว่าโควตามีจำกัดและส่งเท่าที่จำเป็น
- Kaggle ปิด 24 พ.ย., รายงานและซอร์สโค้ดส่ง 30 พ.ย., คะแนน leaderboard คิดเป็น 70% ของเกรด
- ถ้าคะแนนต่ำกว่า baseline เกรดส่วนนี้ = α × (คะแนน / baseline)

## ปัญหางาน 4

ไม่ว่าจะเรียงแถวหรือให้เลขคลาสแบบไหน งาน 4 ที่ส่งเป็นตัวเลขได้คะแนนรวมใกล้ 0.617 เท่ากันหมด ส่วนแบบข้อความได้ต่ำกว่า เมื่อคำนวณแล้ว คะแนนงาน 4 ที่ส่งเป็นตัวเลขอยู่ที่ประมาณ 0.2 ซึ่งเป็นระดับเดาสุ่ม ทั้งที่ holdout ในเครื่องได้ 0.913

- บน Kaggle ไม่มีไฟล์ csv ของงาน 4 มีแค่ README กับ datacard ส่วน test.csv มาจาก zip ใน Google Drive (ไฟล์ลงวันที่ 1 พ.ย. 2025)
- หน้า Data ของ Kaggle บอกว่าภาพขนาด 200x100 แต่ภาพที่ได้มาขนาด 230x120
- สมมติฐานที่เหลือคือเฉลยไม่ตรงกับชุดภาพหรือลำดับที่เรามี ซึ่งแก้จากฝั่งเราไม่ได้

การตัดสินใจ: ใช้ submission.csv (v1) ต่อไป และหยุดใช้โควตาเดาเรื่องงาน 4
